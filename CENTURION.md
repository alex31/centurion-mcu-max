# mcu-max for Centurion

The upstream branch contains the engine files and MIT license from
[mcu-max 1.0.6](https://github.com/Gissio/mcu-max/tree/aa03caffce50729566b5db6965bf735c31f33eea).

The Centurion branch fits the engine to SDCC and a 16-bit CPU6, fixes move
generation from a custom starting position and checks castling through
attacked squares. The CENTOS chess example selects the game configuration.
